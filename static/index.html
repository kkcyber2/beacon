How the merging works

  1. Normalise. Fold accents and case, strip feed HTML, drop stopwords, strip one common suffix so refunds matches refund.
  2. Score every pair. Title overlap (a blend of overlap coefficient and Jaccard) plus entity agreement, attenuated when the two items are far apart in time.
  3. Union-find, not first-match. Greedy clustering cannot merge a chain where A matches B and B matches C but A and C do not. Union-find can, and the result does not depend on input order.
  4. Pick a lead. The earliest published item wins, with the shorter headline breaking ties — the version wired first is usually the original.
